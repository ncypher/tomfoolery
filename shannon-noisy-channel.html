What this instrument is showing: Shannon separated the semantic meaning of a message from the engineering problem of communicating a selected symbol reliably. Entropy describes uncertainty in the source. Source coding exploits predictability. Redundancy can make errors correctable. Channel capacity sets a theoretical ceiling for reliable communication at a given bandwidth and signal-to-noise ratio. This page uses a binary-error toy channel and simple repetition coding for intuition; it is not a full modern communications stack.
